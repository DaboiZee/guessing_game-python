# guessing_game-python
did this little project to both serve as a milestone and test my understanding of fundamentals so far about: The computer randomly selects a number between 1 and 10, and the player has up to 10 attempts to guess it. After each guess the code tells the player whether their guess is too high or too low. The player can then choose whether to start another game. also keeps track of the guess with the lowest number of attempts sort of a best score Features: Random number generation, Up to 10 guesses per game, Higher/lower feedback, Win and loss detection, Play-again option, Best-score tracking, Multiple functions with separate responsibilities, Multiple return values and Boolean state management
what I learned/practiced while making said project: Functions Parameters and arguments, Return values, Multiple return values, while loops, if / elif / else, Boolean variables, User input Variables, and program state Scope and passing information between functions, Basic program structure and decomposition Debugging logical errors
how to run: have python installed and run guessing_game.py then follow terminal instructions 
further improvement could be a UI or Adding difficulty levels
